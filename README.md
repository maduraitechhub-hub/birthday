# Birthday Surprise 💗
1. `npm install` then `npm run dev` (open http://localhost:3000). Deploy: `npm run build && npm start`, or push to Vercel.
2. Edit ONLY `src/data/birthdayData.js` (names, secrets, hints, timeline, memories, surprise, reasons, letter, music).
3. Drop your files into `public/assets/` (birthday, couple, memories, gifs, music, videos). Names must match the paths in the data file. Missing files show a cute placeholder.
Note: the secret answers are checked in the browser, so they're not truly private. It's a fun surprise, not authentication.
